# CCNA Mega Lab — Networking Practice

## Overview

This repository documents my completion of the **CCNA Mega Lab** created by **Jeremy McDowell (Jeremy's IT Lab)**.

I followed Jeremy's provided instructions and worked through the **entire Mega Lab from start to finish** in Cisco Packet Tracer. The lab allowed me to bring together and practice the networking concepts I had been studying in a single, larger network environment.

This repository serves as a record of my **hands-on practice and completion of the lab**.

## Topics Practiced

The lab provided hands-on practice with a wide range of CCNA-level networking technologies, including:

* IPv4 addressing and routing
* IPv6 addressing and routing
* VLANs
* Access and trunk ports
* EtherChannel / LACP / PAgP
* Rapid PVST+
* Root bridge configuration
* PortFast and BPDU Guard
* OSPF
* Static and default routing
* HSRP
* DHCP and DHCP relay
* DNS
* NTP
* SNMP
* Syslog
* SSH
* NAT and PAT
* LLDP
* Access Control Lists (ACLs)
* Port Security
* DHCP Snooping
* Dynamic ARP Inspection
* Wireless LAN configuration
* Cisco Wireless LAN Controller (WLC)

## What I Practiced

Completing the lab gave me an opportunity to practice configuring and troubleshooting a larger Cisco network rather than working with individual concepts in isolation.

Key areas I focused on included:

* Configuring and verifying Layer 2 switching
* Implementing VLANs and trunking
* Configuring Layer 3 routing
* Working with OSPF and network redundancy
* Configuring HSRP
* Implementing common network services
* Applying network security features
* Troubleshooting connectivity and configuration issues
* Verifying network operation using Cisco IOS commands

## Environment

* Cisco Packet Tracer
* Cisco IOS-based routers and switches
* Multi-router and multi-switch topology
* End hosts and network services
